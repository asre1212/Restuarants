# Restaurants icon

Created with the built-in image-generation tool, then exported at 512, 192, 180, and 32 pixels for the manifest, iPhone Home Screen, and favicon. Full-bleed square artwork; the operating system applies its corner mask. The manifest uses `purpose: any` because this artwork is not designed for aggressive circular masks.

Prompt: A polished restaurant notebook icon: deep forest-green background, centered ivory ceramic dinner plate with a refined double rim, ivory fork and knife, one small warm-brass four-point sparkle. Restrained dimensional relief, clear silhouette, balanced space, no text, letters, device mockup, watermark, outer rounded square, or surrounding white margin.

The active assets are `restaurant-512.png`, `restaurant-192.png`, `apple-touch-icon-v2.png`, and `favicon-32.png`. Earlier icons are retained in source history/unused files; app references use the new filenames so installed clients request the updated art.
